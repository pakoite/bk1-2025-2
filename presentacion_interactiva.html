Seguridad — Autenticación (JWT)

JWT: stateless, escalable y firmado. Instalación: pip install PyJWT werkzeug

# Ejemplo: generar token
payload = {..., 'exp': datetime.utcnow() + timedelta(hours=24)}
token = jwt.encode(payload, SECRET_KEY, algorithm='HS256')

Seguridad — Rate Limiting

Usar Flask-Limiter para prevenir brute force y abuso. Ejemplo: @limiter.limit("5 per minute")

Seguridad — Prevención SQLi y .env

Usar sentencias preparadas; NO concatenar input en queries. Mantener credenciales en variables de entorno con python-dotenv.

Seguridad — CORS

Configurar orígenes permitidos con flask-cors. En producción permitir solo dominios específicos.

Manejo de Errores

Usa respuestas estandarizadas y manejadores globales. Incluye códigos 4xx/5xx y excepciones personalizadas.

Base de Datos

Connection Pooling

Reutiliza conexiones para mejorar rendimiento (SQLite/MySQL examples).

Transacciones

Usar commit/rollback en operaciones críticas (p. ej. transferencias).

Migraciones

Usar Alembic para versionar esquema y aplicar migraciones reproducibles.

Validación de Datos

Usa Marshmallow para validar y serializar. Define schemas con campos, validaciones y mensajes claros.

Documentación

Genera documentación interactiva con Swagger (Flasgger). Expone /docs/ y /apispec.json.

Testing

Escribe tests unitarios e integración con pytest; usa fixtures y busca >=80% de cobertura.

Logging y Monitoreo

Configura logs rotativos, middleware para request/response y un endpoint /health con métricas.

Performance

Usa Redis + Flask-Caching, paginación, compresión (flask-compress) y evita N+1 queries.

Deployment

Empaqueta con Docker, sirve con Gunicorn detrás de Nginx, y automatiza con GitHub Actions.

Ejercicios Prácticos

  • Sistema de autenticación completo (JWT, roles).
  • CRUD con validación, paginación y tests.
  • Rate limiting por tipo de usuario.
  • Logging completo y rotación de logs.
  • Deployment con Docker + CI/CD.

Seguridad, tests, monitoring, performance y deployment — todo listo en la guía.
